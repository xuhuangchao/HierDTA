HierDTA 实验清单
============================================================

【公共参数模板】
python training_warmup.py \
  --dataset_idx 1 --gpu_idx 1 \
  --lr 0.001 --batch_size 512 --max_norm 5.0 --epoch 500 --patience 50 --surface_k 5 \
  --drug_hidden 64 --drug_out 128 --n_layers_drug 2 --heads 2 --dropout 0.2 \
  --protein_hidden 128 --protein_out 128 --n_layers_protein 4 --use_surface 1 \
  --emb_dim 128 \
  --use_fingerprint 1 --use_p_global 1 --use_a2p_attn 1 --use_m2p_attn 1 --use_protein_max_pool 1

以下实验只需替换对应的 strategy/seed/消融参数即可。

============================================================
一、基线实验（必须跑，用于对比）
============================================================

1.1 random split — 5 seeds
--------------------------------------------------------------
strategy=random, seed=0,1,2,3,4
max_norm=5.0

1.2 cold_drug split — 5 seeds
--------------------------------------------------------------
strategy=cold_drug, seed=0,1,2,3,4
max_norm=5.0

1.3 cold_target split — 5 seeds（可选）
--------------------------------------------------------------
strategy=cold_target, seed=0,1,2,3,4
max_norm=5.0

1.4 all_cold split — 5 seeds（可选）
--------------------------------------------------------------
strategy=all_cold, seed=0,1,2,3,4
max_norm=5.0

============================================================
二、消融实验（Ablation Studies）
============================================================

说明：以下实验建议在 random split 下进行，每个设置跑 3 个种子（如 1,2,3）。

2.1 去除 Surface 特征（蛋白侧仅保留 ESM 480-dim）
--------------------------------------------------------------
--use_surface 0
其余参数保持基线默认值。

2.2 去除 Fingerprint 分支
--------------------------------------------------------------
--use_fingerprint 0
其余参数保持基线默认值。

2.3 去除 Global ESM 蛋白特征
--------------------------------------------------------------
--use_p_global 0
其余参数保持基线默认值。

2.4 去除 Cross-Attention（a2p + m2p 全关）
--------------------------------------------------------------
--use_a2p_attn 0 --use_m2p_attn 0
此时 multi_level_reps 退化为 global_mean_pool(h_node_p)。

2.5 去除 Protein Max Pool
--------------------------------------------------------------
--use_protein_max_pool 0
其余参数保持基线默认值。

2.6 仅保留 atom->protein 注意力
--------------------------------------------------------------
--use_m2p_attn 0
其余参数保持基线默认值。

2.7 仅保留 motif->protein 注意力
--------------------------------------------------------------
--use_a2p_attn 0
其余参数保持基线默认值。

============================================================
三、架构搜索实验（Architecture Sweep）
============================================================

说明：以下实验建议在 random split 下跑 2-3 个种子，观察趋势。

3.1 更深的药物编码器
--------------------------------------------------------------
--n_layers_drug 3
（默认 2 层，测试 3 层对丰富特征的利用能力）

3.2 更宽的药物编码器
--------------------------------------------------------------
--drug_hidden 128 --drug_out 128 --emb_dim 128
（注意：drug_out 和 emb_dim 必须相等）

3.3 更多注意力头
--------------------------------------------------------------
--heads 4
（默认 2 头，测试 4 头对异构图中多关系建模的帮助）

3.4 更浅的蛋白编码器
--------------------------------------------------------------
--n_layers_protein 2
（默认 4 层，测试是否过深）

3.5 更深的蛋白编码器
--------------------------------------------------------------
--n_layers_protein 6
（测试蛋白侧是否欠拟合）

3.6 不同的 dropout
--------------------------------------------------------------
--dropout 0.1
或
--dropout 0.3

============================================================
四、冷启动专项实验
============================================================

4.1 cold_drug + 去除 fingerprint
--------------------------------------------------------------
strategy=cold_drug, --use_fingerprint 0
（测试指纹是否在冷药物场景下成为噪音）

4.2 cold_drug + 更深的 drug encoder
--------------------------------------------------------------
strategy=cold_drug, --n_layers_drug 3
（冷药物下分子侧泛化性更重要，测试增加深度是否有帮助）

4.3 cold_drug + 更大的 drug_hidden
--------------------------------------------------------------
strategy=cold_drug, --drug_hidden 128 --drug_out 128 --emb_dim 128

4.4 cold_drug + 去除 surface
--------------------------------------------------------------
strategy=cold_drug, --use_surface 0

============================================================
五、快速验证实验（单种子，用于调参）
============================================================

说明：以下设置仅跑 seed=1，epoch 可降至 200，patience=30，快速验证方向。

5.1 小 batch 高 lr
--------------------------------------------------------------
--batch_size 256 --lr 0.002

5.2 大 batch 低 lr
--------------------------------------------------------------
--batch_size 1024 --lr 0.0005

5.3 强正则
--------------------------------------------------------------
--dropout 0.3 --max_norm 3.0

============================================================
六、推荐执行顺序
============================================================

阶段 1（第 1 周）：
  - 1.1 random baseline（5 seeds）
  - 2.1 ~ 2.7 消融实验（各 3 seeds）

阶段 2（第 2 周）：
  - 1.2 cold_drug baseline（5 seeds）
  - 4.1 ~ 4.4 冷启动专项

阶段 3（第 3 周）：
  - 3.1 ~ 3.6 架构搜索
  - 5.1 ~ 5.3 快速验证（如有余力）

阶段 4（第 4 周）：
  - 1.3 cold_target（可选）
  - 1.4 all_cold（可选）
  - 根据前期结果做补充实验
